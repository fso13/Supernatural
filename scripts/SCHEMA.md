# Схема карточки бестиария (обязательна к соблюдению)

Каждое существо — **отдельный JSON-файл** в `data/creatures/<slug>.json`.
Файл должен быть валидным JSON (UTF-8, без комментариев, без markdown-обёртки).

## Обязательные правила

1. **Поля `slug`, `name_ru`, `name_en`, `category`, `kind`, `summary`, `lore`, `powers`,
   `weaknesses`, `hunting`, `dnd`, `dnd_notes` — обязательны и непусты.**
2. `slug` берётся ровно из имени файла вики-выжимки (без `.txt`).
3. `category` — строго одно из: `Монстр`, `Демон`, `Ангел`, `Божество`, `Дух`, `Ведьма`,
   `Левиафан`, `Иное`.
4. `kind` — строго одно из: `creature` (живое/неживое существо), `being` (высшая сущность,
   божество, персонификация), `place` (локация), `artifact` (артефакт/предмет),
   `lore` (понятие, организация, явление).
5. `threat` — целое 1–5, опасность **внутри вселенной сериала**:
   1 — одна жертва в неделю, убивается рядовым охотником;
   3 — серьёзная угроза, нужна подготовка;
   5 — угроза миру/архангел/первичная сущность.
6. `abilities` — ровно 6 ключей, целые числа 1–30. Для нежити/конструктов INT может быть 1–3.
7. `cr` — строка, например `"0"`, `"1/2"`, `"5"`, `"23"`. `pb` — бонус мастерства числом.
   `xp` — целое. Согласованность CR↔XP↔PB обязательна (таблица 5e), для CR > 30 ставь `pb: 9`.
8. `hp` — строка вида `"82 (11d8 + 33)"`; `ac` — строка; `speed` — строка.
9. Русские термины 5e: fт. — футы, «преимущество», «помеха», «спасбросок Ловкости (Сл 15)».
   Названия характеристик: Сил, Лов, Тел, Инт, Мдр, Хар.
10. **Ничего не выдумывать про сериал.** Всё фактическое (силы, слабости, сезоны, имена,
    эпизоды) — только из предоставленного файла вики. Если данных нет — сузь формулировку
    или оставь поле пустым (`""` / `[]`), но не сочиняй.
11. Механику D&D можно и нужно домысливать — это адаптация, а не пересказ.
12. Типы существ 5e: `Исчадие`, `Небожитель`, `Демон`, `Дьявол`, `Нежить`, `Фея`,
    `Аберрация`, `Великан`, `Зверь`, `Монстр`, `Элементаль`, `Конструкт`, `Гуманоид`, `Слизь`, `Растение`.
13. Для `kind` = `place`/`artifact`/`lore` блок `dnd` всё равно заполняется — но как
    «опасность/энкаунтер-элемент»: вместо боевых действий описывай ловушки, эффекты,
    свойства предмета, требования к ритуалу (используй поля `traits` и `lair_actions`).
14. Объём: `lore` 900–1800 знаков, `summary` 120–300 знаков, каждый пункт `powers`/`weaknesses`
    40–220 знаков, `hunting` 200–500 знаков, `tactics` 250–600 знаков, `ecology` 150–450 знаков,
    `dnd_notes` 250–600 знаков. У крупных существ (архангелы, Левиафаны, Смерть, Тьма)
    допустим верхний предел и легендарные действия.

## Именование по-русски

Используй устоявшиеся в русском фандоме переводы: `Sam Winchester` → `Сэм Винчестер`,
`Dean` → `Дин`, `Castiel` → `Кастиэль`, `Crowley` → `Кроули`, `Leviathans` → `Левиафаны`,
`Wendigo` → `Вендиго`, `Djinn` → `Джинн`, `Rugaru` → `Ругару`, `Shtriga` → `Штрига`,
`Reapers` → `Жнецы`, `Knights of Hell` → `Рыцари Ада`, `Men of Letters` → `Люди Письма`,
`Purgatory` → `Чистилище`, `Angel Blade` → `ангельский клинок`.
