# Схема карточки «The Edge!» (обязательна к соблюдению)

Система: **«The Edge!»** — только **d6**. Проверка: `2d6 (светлый + тёмный) + атрибут + ранг навыка ≥ ЧЦ`.
При успехе читают **светлый** кубик (степень), при провале — **тёмный** (цена + обязательный шаг вперёд).

Каждое существо — **отдельный JSON-файл** в `data/edge/<slug>.json`.
Валидный JSON, UTF-8, без markdown внутри значений.

## Структура

```json
{
  "slug": "djinn",
  "name_ru": "Джинны",
  "name_en": "Djinn",
  "category": "Монстр",
  "kind": "creature",
  "threat": 3,
  "ugroza": "высокая",

  "look": "1–2 предложения: что охотники видят и понимают при первой встрече. Конкретно, без эпитетов вроде «ужасный».",

  "special": [
    { "name": "Грёза", "text": "Механика в терминах «The Edge!»: ЧЦ, ОД, раны, стресс, дистанция." }
  ],

  "weakness": "Правило: чем существо можно убить и что для этого нужно. Обязательно через знание — сначала узнать, потом применить.",

  "learn": [
    { "skill": "Магические знания", "attr": "Разум", "cch": 12,
      "text": "Что именно узнают охотники этой проверкой." }
  ],

  "notes": "1–2 предложения хранителю: как вести сцену, чего существо боится, какую ошибку легко совершить."
}
```

## Что берётся из скелета, а что пишешь ты

**Числа бери из `skeleton` во входном файле и НЕ меняй:**
`ugroza`, `attrs` (Тело/Ловкость/Разум/Воля), `wounds`, `stress`, `armor`, `defense`, `weapon`.
Перенеси их в файл символ в символ.

**Пишешь сам:** `look`, `special`, `weakness`, `learn`, `notes`.

## Правила

1. **Обязательные поля:** все из структуры выше, кроме `armor` (может быть 0) и `stress` (может быть `null`).
2. `slug` — ровно как имя файла в `data/creatures/`.
3. `category` — одно из: `Монстр`, `Демон`, `Ангел`, `Божество`, `Дух`, `Ведьма`, `Левиафан`, `Иное`.
4. `kind` — одно из: `creature`, `being`, `place`, `artifact`, `lore`.
5. `threat` — целое 1–5, **скопируй из D&D-карточки**.

### `special` — не больше двух

Это правило самой системы: в бестиарии «The Edge!» у существа **одна-две особенности, не больше**.
Не переноси сюда весь список сил из D&D-версии. Выбери **самое характерное** — то, ради чего
существо узнаваемо. Если хочется добавить третье — значит, одно из двух лишнее.

Механику пиши строго в терминах системы:
- проверки: `2d6 + Воля ≥ 13`, `ЧЦ 11`;
- ресурсы: `1 ОД`, `2 ОД`, `−1 искра`, `1 рана`, `2 стресса`;
- дистанции: `Рукопашная`, `Рядом`, `Даль`;
- состояние: `−1 к следующей проверке в сцене`, `сдвиг на Рядом`.

Не используй D&D-слова: «спасбросок», «КД», «хиты», «раунд действия», «преимущество».
Правильные: **ЧЦ**, **ЧЦ защиты**, **раны**, **стресс**, **ОД**, **дистанция**, **сдвиг**, **искра**.

### `weakness` — главное поле

В «Сверхъестественном» тварь убивает **знание**, а не урон. Формулируй так:
**что нужно узнать** и **что потом сделать**. Пример:

> «Знание: джинна берёт только серебро, смоченное бараньей кровью (Магические знания, ЧЦ 13).
> Применение: смачивать клинок перед самым ударом — кровь сохнет за десять минут. Обычное
> оружие раны наносит, но джинн восстанавливает 2 раны в начале хода, пока рядом спящий.»

Если у существа слабости нет (в источнике её нет) — так и напиши: «Слабости в источниках нет».

### `learn` — 2–3 проверки

Каждая — способ, которым охотники **узнают** что-то полезное: слабость, повадку, место логова,
как отличить от похожей твари.

Поля: `skill` (навык), `attr` (атрибут), `cch` (число цели), `text` (что узнают).

**Навыки бери только из списка** (это навыки «The Edge!»):

- **Бой:** `Рукопашное оружие`, `Двуручное оружие`, `Оружие и щит`, `Двойное оружие`, `Стрельба`, `Безоружный бой`, `Лёгкая броня`, `Тяжёлая броня`
- **Общение:** `Дипломатия`, `Запугивание`, `Обман`, `Выступление`, `Проницательность`, `Этикет`, `Торговля`, `Право и обычай`
- **Знание:** `История`, `Природа`, `Религия`, `Магические знания`, `Анализ`, `Ремесло`, `Алхимия`, `Медицина`, `Подделка`
- **Тело и движение:** `Атлетика`, `Акробатика`, `Скрытность`, `Внимание`, `Выживание`, `Взлом`, `Верховая езда`
- **Современность** (модуль, для охотников подходит): `Огнестрел`, `Вождение`, `Техника`, `Уличное чутьё`

**Атрибут** — один из четырёх: `Тело`, `Ловкость`, `Разум`, `Воля`.
**ЧЦ** — по шкале системы: тривиально 7, легко 8–9, обычно 10–11, трудно 12–13,
опасно 14–15, экстремально 16–17, легендарно 18+.
Бери **10–14**: улика не должна висеть за легендарной проверкой.

Смысл проверок — как в сериале: `Анализ` по телу, `Магические знания` по символам,
`Проницательность` по свидетелю, `История` по старым газетам, `Природа` по следам в лесу.

### `look` и `notes`

- `look` — физика. Не «жуткое зрелище», а «под ногтями земля, глаза не мигают».
- `notes` — что хранителю важно помнить за столом.

## Тон

Тексты по-русски, сухо и конкретно, как в настоящем бестиарии. Никаких «это очень опасно».
Только то, что хранитель применит за столом прямо сейчас.

## Источники

Пиши **только** по D&D-карточке существа из входного файла. Ничего не выдумывай про сериал.
Механику «The Edge!» — придумывай свободно, это адаптация.
