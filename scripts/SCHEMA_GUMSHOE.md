# Схема карточки GUMSHOE (обязательна к соблюдению)

Каждое существо — **отдельный JSON-файл** в `data/gumshoe/<slug>.json`.
Валидный JSON, UTF-8, без markdown внутри значений.

## Структура

```json
{
  "slug": "djinn",
  "name_ru": "Джинны",
  "name_en": "Djinn",
  "category": "Монстр",
  "kind": "creature",
  "threat": 3,

  "horror": "1–2 предложения: что видят сыщики в момент первой встречи. Конкретно, физически, без эпитетов вроде «ужасный».",

  "abilities": {
    "Атлетика": 6,
    "Бой": 7,
    "Здоровье": 12,
    "Бдительность": 6,
    "Скрытность": 8
  },
  "hit_threshold": 4,
  "damage": "Когти +1; отравляющее касание — потеря Стабильности 3 и уход в грёзу",
  "armor": "—",
  "stability": { "test": 3, "witnessed": 5 },

  "special": [
    { "name": "Грёза", "text": "Механика в терминах GUMSHOE: что бросают, против чего, что происходит при провале." }
  ],

  "clues": [
    { "ability": "Оккультизм", "text": "Что именно узнают сыщики, имея эту способность." },
    { "ability": "Архивы", "spend": 1, "text": "Что даёт дополнительная трата очка." }
  ],
  "core_clue": "Одна фраза: улика, без которой дело не сдвинется.",

  "rule": "Как существо можно убить/остановить — в терминах системы: какие способности нужны, какие очки тратятся, сколько времени это занимает.",
  "notes": "2–4 предложения ведущему: как вести сцену, чего боится существо, какую ошибку легко совершить."
}
```

## Правила

1. **Обязательные поля:** `slug`, `name_ru`, `name_en`, `category`, `kind`, `threat`,
   `horror`, `abilities`, `hit_threshold`, `damage`, `stability`, `special`, `clues`,
   `core_clue`, `rule`, `notes`.
2. `slug` — ровно как имя файла в `data/creatures/`.
3. `category` — одно из: `Монстр`, `Демон`, `Ангел`, `Божество`, `Дух`, `Ведьма`, `Левиафан`, `Иное`.
4. `kind` — одно из: `creature`, `being`, `place`, `artifact`, `lore`.
5. `threat` — целое 1–5, **скопируй из D&D-карточки**.

### Числовые поля — считай строго по формулам, они уже посчитаны в `data/gumshoe/skeleton.json`

Не меняй числа из скелета. Если скелет не даёт способность (например, у существа нет
Стрельбы) — не добавляй её.

- **Бдительность** — насколько трудно существо застать врасплох.
- **Здоровье** — в GUMSHOE это небольшие числа (человек 6–10, монстр 10–30,
  боссы 30–45). Не ставь 100.
- **Порог попадания (Hit Threshold)** — обычно 3–5. Всё, что выше 5, почти неуязвимо:
  используй только для архетипов и первичных сущностей.
- **Урон** — формат GUMSHOE: `Название +N` (модификатор к броску урона), плюс отдельно
  описанные эффекты (потеря Стабильности, болезнь, захват).
- **Потеря Стабильности** — `test` (при успешной проверке Воли/Стабильности) и
  `witnessed` (когда существо делает что-то чудовищное на глазах). Диапазон 0–8.
  Для обычных людей и мелких монстров ставь 0 в обоих полях.

### Смысловые поля

- `horror` — **только физическое описание**. Не «ужасное зрелище», а «кожа под глазами
  лопается и оттуда идёт пар».
- `special` — 2–5 способностей. Механику пиши в терминах GUMSHOE: «проверка Бдительности
  против Сл 4», «трата 2 очков Боя», «потеря Стабильности 4 при провале».
- `clues` — **3–5 улик**. Каждая привязана к расследовательской способности из списка ниже.
  Формулируй так, будто сыщик уже потратил время: «На внутренней стороне бедра — след
  от трубки. Кто-то держал жертву живой неделями».
  - Если улика даёт **только** базовую информацию — поле `spend` не нужно.
  - Если за очко способности можно вытянуть больше — укажи `"spend": 1` (или 2).
- `core_clue` — одна фраза. Это улика, без которой дело встанет.
- `rule` — обязательно через **знание**: сначала нужно узнать правило (какая способность
  его открывает), потом применить. Так устроен GUMSHOE.
- `notes` — советы ведущему.

## Список расследовательских способностей (используй только эти названия)

**Академические:** `Антропология`, `Археология`, `Архивы`, `История`, `Оккультизм`,
`Демонология`, `Теология`, `Медицина`, `Языки`, `Криптозоология`, `Химия`, `Баллистика`

**Межличностные:** `Допрос`, `Запугивание`, `Лесть`, `Ложь`, `Проницательность`,
`Уличное чутьё`, `Репутация`

**Технические:** `Осмотр места`, `Взлом`, `Слежка`, `Наружное наблюдение`,
`Эксплуатация`, `Фотосъёмка`

## Список общих способностей (используй только эти названия)

`Атлетика`, `Бой`, `Стрельба`, `Здоровье`, `Стабильность`, `Бдительность`, `Скрытность`,
`Вождение`, `Подготовка`, `Связи`, `Воля`, `Вера`

## Тон

Тексты — по-русски, сухо и конкретно, как в настоящем модуле. Никаких «это очень опасно».
Только то, что ведущий может сразу использовать за столом.

## Источники

Пиши **только** по предоставленной D&D-карточке существа (она лежит рядом в
`data/creatures/<slug>.json`) и по скелету. Ничего не выдумывай про сериал.
Механику GUMSHOE — придумывай свободно, это адаптация.
