# Бестиарий «Сверхъестественного» + D&D 5e

Полный бестиарий существ из сериала **«Сверхъестественное»** (*Supernatural*, The CW, 2005–2020)
с адаптацией каждого существа под правила **Dungeons & Dragons 5e** — плюс статический сайт-бестиарий
с поиском, фильтрами и печатными статблоками.

## Что получилось

Бестиарий собран в **трёх редакциях**: под Dungeons & Dragons 5e, под GUMSHOE («Сыщик»)
и под авторскую систему «The Edge!». Общая точка входа — [index.html](index.html).

| | |
|---|---|
| Всего записей | **354** |
| Существа и высшие сущности | **295** (198 существ + 97 высших сущностей) |
| Приложение: локации, артефакты, организации, понятия | **59** |
| Категории | Монстр 106 · Божество 71 · Иное 50 · Демон 42 · Ангел 39 · Дух 31 · Ведьма 10 · Левиафан 5 |
| Диапазон CR | 0 – 30 |
| Изображения | **277 из 354** (кадры с Supernatural Wiki, 7,7 МБ) |
| Источник фактов | [Supernatural Wiki](https://supernatural.fandom.com) (выжимки в `data/raw/wiki/`) |

У каждой записи есть **изображение**: кадр из сериала, промо или фото персонажа с вики.
Для 77 существ картинки на вики нет вовсе (это монстры из романов и спиноффов,
которые ни разу не появлялись на экране) — вместо случайной чужой фотографии
показывается аккуратная заглушка с иконкой категории и названием.

Каждая запись содержит: русское и английское название, псевдонимы, сезоны и первое появление,
описание (лор), список сил, список слабостей, способ охоты/убийства, известных особей
и **полный статблок 5e** — размер, тип, мировоззрение, КД, хиты, скорость, шесть характеристик,
спасброски, навыки, сопротивления/иммунитеты/уязвимости, чувства, языки, БМ, CR и опыт,
особенности, действия, бонусные действия, реакции, легендарные действия, действия в логове,
тактику, экологию и заметки мастеру.

## Как открыть сайт

Вариант 1 — просто открыть файл (всё работает без сборки и без интернета):

```
open site/index.html
```

Вариант 2 — локальный сервер:

```
bash scripts/serve.sh          # http://127.0.0.1:8770
```

## Возможности сайта

- **Бестиарий** — карточки с изображением, поиском по русскому и английскому названию,
  псевдонимам, лору, силам и слабостям. Фильтры: категория, опасность в сериале (1–5),
  диапазон CR, сезон. Сортировка по названию, опасности, CR и первому сезону.
- **Карточка существа** — открывается по клику (и по прямой ссылке вида `index.html#wendigo`):
  большой кадр, лор, силы, слабости, способ охоты и статблок 5e в оформлении официальных правил.
- **Мир и артефакты** — локации (Чистилище, Ад, Рай, Клетка Люцифера, Мир Апокалипсиса),
  артефакты (Первое Лезвие, Скрижали, Уравнитель, Печать Каина) и организации
  (Люди Письма, охотники, ковены) с игровыми свойствами и «действиями в логове».
- **Таблицы** — сводка по CR от сильных к слабым, состав бестиария по категориям,
  новые существа по сезонам и готовые подборки энкаунтеров по тирам (уровни 1–4, 5–10, 11–16, 17+).
- **Экспорт** — кнопки «⤓ JSON», «⤓ Markdown» и «🖨 Печать» (есть отдельная печатная раскладка).
- Ссылки с фильтрами: `index.html?cat=Демон&crmin=15&sort=cr`.

## Методика

1. По MediaWiki API собран список страниц существ (1463 страницы в 72 категориях).
2. Страницы разделены на «виды/типы» и «именных персонажей»; вручную отобран мастер-список
   значимых записей (виды, Альфы, архангелы, Принцы Ада, Рыцари Ада, Всадники, боги пантеонов,
   ключевые именные сущности).
3. Для каждой записи загружен викитекст, из него вырезаны инфобокс, описание, силы и способности,
   слабости, характеристики, история и появления — получилась компактная выжимка 1–5 КБ.
4. По выжимкам написаны русские карточки и статблоки 5e по единой схеме (`scripts/SCHEMA.md`),
   с автоматической проверкой: обязательные поля, допустимые категории и типы, шесть характеристик
   в диапазоне 1–30, согласованность CR ↔ опыт ↔ бонус мастерства, объёмы разделов.
5. Все 354 карточки прошли валидацию без замечаний; сайт собран из них одной командой.

# Третья редакция: «The Edge!»

Тот же бестиарий под авторскую модульную систему **«The Edge!»** из проекта `me-rpg`:
**только d6**, пара кубиков — **светлый** и **тёмный**, четыре атрибута, раны и стресс.

**Сайт:** [site-edge/index.html](site-edge/index.html) ·
**правила:** [site-edge/rules.html](site-edge/rules.html) ·
**приключение:** [site-edge/adventure.html](site-edge/adventure.html)

Общая точка входа для трёх редакций — [index.html](index.html).

## Что меняется

| | D&D 5e | GUMSHOE | **The Edge!** |
|---|---|---|---|
| Кубики | к20 + модификаторы | 1к6 + трата очков | **2d6: светлый + тёмный** |
| Проверка | против Сл | улика без броска | `2d6 + атрибут + ранг ≥ ЧЦ` |
| Успех | есть или нет | трата очков | **светлый кубик: насколько хорошо** |
| Провал | «не вышло» | — | **тёмный кубик: цена + обязательный шаг вперёд** |
| Ресурсы | хиты, CR | Здоровье, Стабильность | **раны, стресс, 2 ОД** |
| Бой | инициатива, клетки | короткая развязка | **дистанции Рукопашная / Рядом / Даль** |

Ключевое совпадение с сериалом: **в «The Edge!» провал без шага вперёд запрещён правилами**.
Братья Винчестеры почти никогда не «просто проваливают» проверку — они теряют ночь, шумят,
злят шерифа и всё равно находят зацепку. Система требует от хранителя того же.

## Карточки «The Edge!»

У каждой из 354 записей:

- **Угроза** — низкая, средняя, высокая, очень высокая, смертельная
- **Четыре атрибута** — Тело, Ловкость, Разум, Воля
- **Раны**, **Стресс**, **Доспех**, **ЧЦ защиты** = 8 + Ловкость + доспех
- **Оружие** — `Название +N (дистанция)`; урон = (итог атаки − ЧЦ) + N
- **Особое** — **не больше двух** особенностей. Это правило самой системы, а не экономия места
- **Слабость** — сначала что нужно **узнать**, потом что **сделать**
- **Как узнать** — 2–3 проверки (`навык`, `атрибут`, `ЧЦ`), которыми выясняется слабость
- **Заметки хранителю**

## Откуда числа

Формулы выведены из статблоков D&D 5e и полностью приведены на странице правил:

| Показатель | Формула |
|---|---|
| Атрибут | round(модификатор D&D / 1,5) + 2, от 0 до 8 |
| Раны | 6 + Тело + round(CR / 2), от 3 до 40 |
| Стресс | 6 + Воля (у бессознательных тварей — не используется) |
| Доспех | round((КД − 12) / 2), от 0 до 5 |
| ЧЦ защиты | 8 + Ловкость + доспех |
| Бонус оружия | round(средний урон атаки / 7), от 0 до 5 |

# Фирменный стиль

Сайт оформлен в визуальном языке сериала. Все эмблемы — **оригинальная графика**,
нарисованная для проекта в SVG; логотип Warner Bros. не используется и не воспроизводится.

| Знак | Что это | Где |
|---|---|---|
| **Ловушка дьявола** | пентаграмма в двойном круге с насечками | знак в шапке всех страниц, водяной знак в карточке существа, пустые состояния |
| **Пентаграмма** | знак в круге | эмблема редакции D&D 5e, фавикон |
| **Звезда Людей Письма** | гексаграмма в круге | эмблема редакции GUMSHOE |
| **Соляная линия** | рассыпанная соль | разделитель перед подвалом |
| **Энохианское письмо** | полоса знаков | подвал главной страницы |
| **Ночное шоссе** | перспектива дороги | фон героя главной страницы |

Плюс **заставка серии** — светящийся заголовок с медленной пульсацией, как в
титрах: класс `.wordmark`. И знак на обложках печатных книг.

## Файлы

```
assets/
  brand.css               фирменные стили (подключаются всеми редакциями)
  brand/
    devils-trap.svg       ловушка дьявола
    sigil-star.svg        пентаграмма
    men-of-letters.svg    звезда Людей Письма
    salt-line.svg         соляная линия
    enochian-band.svg     энохианское письмо
    road.svg              ночное шоссе
    impala.svg            чёрная машина
    favicon.svg           иконка сайта
```

## Как это сделано

Знаки подключены **CSS-масками**, а не картинками: цвет берётся из `currentColor`.
Поэтому одна и та же эмблема работает и красной в шапке, и золотой в разделителе,
и чёрной на печати.

```css
.sig { background-color: currentColor; mask: var(--sig) center/contain no-repeat; }
.sig-trap { --sig: url("brand/devils-trap.svg"); }
```

> **Почему не `<img src="…svg">`.** `currentColor` внутри внешнего SVG, подключённого
> через `<img>` или `background-image`, **не наследуется** от страницы — знак рисуется
> чёрным. Поэтому все эмблемы идут через маску, а знак на обложке книги встроен в HTML
> как inline-SVG.

## Публикация на GitHub Pages

Сайт собирается и публикуется автоматически при пуше в `master`
(workflow [`.github/workflows/pages.yml`](.github/workflows/pages.yml)).

```
push в master  →  python3 scripts/build_pages.py  →  public/  →  GitHub Pages
```

**Адрес сайта:** <https://fso13.github.io/Supernatural/>

### Что делает пайплайн

1. забирает репозиторий и ставит Python 3.12;
2. проверяет, что все карточки бестиария — валидный JSON (падает, если нет);
3. собирает `public/` скриптом [`scripts/build_pages.py`](scripts/build_pages.py);
4. загружает артефакт и публикует его через `actions/deploy-pages`.

Сборка ничего не компилирует: сайт статический, скрипт только копирует нужное
в `public/` и переименовывает PDF в ASCII-имена. Структура внутри `public/`
повторяет корень репозитория, поэтому относительные ссылки между редакциями
(`../site/img/`, `../assets/`) работают без правок.

### Если Pages ещё не включён

Workflow делает это сам (`enablement: true` в `actions/configure-pages`).
Если по какой-то причине не сработает — **Settings → Pages → Build and
deployment → Source → GitHub Actions**, затем перезапустить job.

### Локальная проверка того, что уедет на Pages

```bash
python3 scripts/build_pages.py                    # собрать public/
python3 -m http.server 8080 --directory public    # посмотреть
```

### Пересборка PDF

```bash
bash scripts/serve.sh          # в одном окне
bash scripts/make_pdfs.sh      # в другом
```
