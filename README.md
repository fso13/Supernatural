# Бестиарий «Сверхъестественного» + D&D 5e

Полный бестиарий существ из сериала **«Сверхъестественное»** (*Supernatural*, The CW, 2005–2020)
с адаптацией каждого существа под правила **Dungeons & Dragons 5e** — плюс статический сайт-бестиарий
с поиском, фильтрами и печатными статблоками.

## Что получилось

Бестиарий собран в **трёх редакциях**: под Dungeons & Dragons 5e, под GUMSHOE («Сыщик»)
и под авторскую систему «The Edge!». Общая точка входа — [index.html](index.html).

| | |
|---|---|
| Всего записей | **354** |
| Существа и высшие сущности | **295** (198 существ + 97 высших сущностей) |
| Приложение: локации, артефакты, организации, понятия | **59** |
| Категории | Монстр 106 · Божество 71 · Иное 50 · Демон 42 · Ангел 39 · Дух 31 · Ведьма 10 · Левиафан 5 |
| Диапазон CR | 0 – 30 |
| Изображения | **277 из 354** (кадры с Supernatural Wiki, 7,7 МБ) |
| Источник фактов | [Supernatural Wiki](https://supernatural.fandom.com) (выжимки в `data/raw/wiki/`) |

У каждой записи есть **изображение**: кадр из сериала, промо или фото персонажа с вики.
Для 77 существ картинки на вики нет вовсе (это монстры из романов и спиноффов,
которые ни разу не появлялись на экране) — вместо случайной чужой фотографии
показывается аккуратная заглушка с иконкой категории и названием.

Каждая запись содержит: русское и английское название, псевдонимы, сезоны и первое появление,
описание (лор), список сил, список слабостей, способ охоты/убийства, известных особей
и **полный статблок 5e** — размер, тип, мировоззрение, КД, хиты, скорость, шесть характеристик,
спасброски, навыки, сопротивления/иммунитеты/уязвимости, чувства, языки, БМ, CR и опыт,
особенности, действия, бонусные действия, реакции, легендарные действия, действия в логове,
тактику, экологию и заметки мастеру.

## Как открыть сайт

Вариант 1 — просто открыть файл (всё работает без сборки и без интернета):

```
open site/index.html
```

Вариант 2 — локальный сервер:

```
bash scripts/serve.sh          # http://127.0.0.1:8770
```

## Возможности сайта

- **Бестиарий** — карточки с изображением, поиском по русскому и английскому названию,
  псевдонимам, лору, силам и слабостям. Фильтры: категория, опасность в сериале (1–5),
  диапазон CR, сезон. Сортировка по названию, опасности, CR и первому сезону.
- **Карточка существа** — открывается по клику (и по прямой ссылке вида `index.html#wendigo`):
  большой кадр, лор, силы, слабости, способ охоты и статблок 5e в оформлении официальных правил.
- **Мир и артефакты** — локации (Чистилище, Ад, Рай, Клетка Люцифера, Мир Апокалипсиса),
  артефакты (Первое Лезвие, Скрижали, Уравнитель, Печать Каина) и организации
  (Люди Письма, охотники, ковены) с игровыми свойствами и «действиями в логове».
- **Таблицы** — сводка по CR от сильных к слабым, состав бестиария по категориям,
  новые существа по сезонам и готовые подборки энкаунтеров по тирам (уровни 1–4, 5–10, 11–16, 17+).
- **Экспорт** — кнопки «⤓ JSON», «⤓ Markdown» и «🖨 Печать» (есть отдельная печатная раскладка).
- Ссылки с фильтрами: `index.html?cat=Демон&crmin=15&sort=cr`.

## Методика

1. По MediaWiki API собран список страниц существ (1463 страницы в 72 категориях).
2. Страницы разделены на «виды/типы» и «именных персонажей»; вручную отобран мастер-список
   значимых записей (виды, Альфы, архангелы, Принцы Ада, Рыцари Ада, Всадники, боги пантеонов,
   ключевые именные сущности).
3. Для каждой записи загружен викитекст, из него вырезаны инфобокс, описание, силы и способности,
   слабости, характеристики, история и появления — получилась компактная выжимка 1–5 КБ.
4. По выжимкам написаны русские карточки и статблоки 5e по единой схеме (`scripts/SCHEMA.md`),
   с автоматической проверкой: обязательные поля, допустимые категории и типы, шесть характеристик
   в диапазоне 1–30, согласованность CR ↔ опыт ↔ бонус мастерства, объёмы разделов.
5. Все 354 карточки прошли валидацию без замечаний; сайт собран из них одной командой.

## Откуда числа

Показатели выведены из статблоков D&D 5e по открытым формулам (полностью приведены на
странице правил). Ничего не «на глаз»: Здоровье = round(хиты / 7) + 2,
Порог попадания = 3 + round((КД − 12) / 4), потеря Стабильности — от «опасности в сериале»
с множителем 1,35 для нежити, аберраций и исчадий.

### Что отличает эту версию от базового GUMSHOE

**Два счётчика вместо одного.** `Стабильность` — краткосрочные нервы, восстанавливаются
через Источники стабильности (людей). `Убеждённость` — вера в то, что мир познаваем
и стоит того; **не восстанавливается обычными способами и не растёт никогда**. На нуле
охотник уходит из дела — и становится кем-то другим (таблица на 1d6).

**Правило твари.** Пока слабость существа не установлена, любая атака наносит ровно
**1 урона**. Тварь нельзя убить не потому, что мастер запрещает, а потому что мир так
устроен. Правило устанавливается расследовательскими способностями.

**Обряды как работа, а не как заклинания.** Экзорцизм, ловушка дьявола, соляной круг,
освящение, сигил изгнания ангелов — у каждого пять параметров: способность, время, Сл,
компоненты, цена. Провал обряда страшнее, чем его отсутствие.

**Шесть архетипов с готовыми цифрами** плюс 18 узлов архетипа — постоянных бонусов,
привязанных к тому, как охотник работает.
