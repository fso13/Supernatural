# Бестиарий «Сверхъестественного» — три редакции

Неофициальный фанатский проект по сериалу **Supernatural**: бестиарий всех существ
в трёх ролевых системах, приключение для каждой и полные правила охоты.

**Сайт: <https://fso13.github.io/Supernatural/>**

---

## Что получилось

**354 записи** — 295 существ и высших сущностей плюс 59 локаций, артефактов и понятий.
**269 иллюстраций.** Три редкости правил: под Dungeons & Dragons 5e, под GUMSHOE
(«Сыщик») и под авторскую систему «The Edge!».

Каждая запись представлена в трёх видах: карточка на сайте, статблок в Markdown-книге
и свёрстанный PDF.

| | D&D 5e | GUMSHOE | The Edge! |
|---|---|---|---|
| **Кубики** | к20 + модификаторы | 1к6 + трата очков | 2d6: светлый + тёмный |
| **Проверка** | против Сл | улика без броска | `2d6 + атрибут + ранг ≥ ЧЦ` |
| **Провал** | «не вышло» | — | цена + обязательный шаг вперёд |
| **Ресурсы** | хиты, CR | Здоровье, Стабильность | раны, стресс, 2 ОД |
| **Бой** | инициатива, клетки | короткая развязка | дистанции Рукопашная / Рядом / Даль |

## Как открыть сайт

Локально, без сборки и без интернета:

```bash
open index.html                     # точка входа: выбор редакции
bash scripts/serve.sh               # или сервер на http://127.0.0.1:8770
```

Опубликованная версия — <https://fso13.github.io/Supernatural/>.

## Возможности сайта

- **Бестиарий** — карточки с изображением, поиском по русскому и английскому названию,
  псевдонимам, лору, силам и слабостям. Фильтры: категория, опасность, сезон, диапазон
  параметров. Сортировка по названию, опасности и первому появлению.
- **Карточка существа** — открывается по клику и по прямой ссылке вида
  `site/index.html#wendigo`: большой кадр, лор, силы, слабости, способ охоты и статблок.
- **Мир и артефакты** — локации (Чистилище, Ад, Рай, Клетка Люцифера, Мир Апокалипсиса),
  артефакты (Первое Лезвие, Скрижали, Уравнитель, Печать Каина) и организации
  (Люди Письма, охотники, ковены).
- **Таблицы** — сводка по уровням опасности, состав бестиария по категориям, новые
  существа по сезонам и готовые подборки энкаунтеров по тирам.
- **Экспорт** — кнопки «⤓ JSON», «⤓ Markdown» и «🖨 Печать» с отдельной раскладкой.
- Ссылки с фильтрами: `site/index.html?cat=Демон&crmin=15&sort=cr`.

# Вторая редакция: GUMSHOE («Сыщик»)

**Сайт:** [site-gumshoe/index.html](site-gumshoe/index.html) ·
**правила:** [site-gumshoe/rules.html](site-gumshoe/rules.html) ·
**лист персонажа:** [site-gumshoe/sheet.html](site-gumshoe/sheet.html) ·
**быстрый старт:** [site-gumshoe/quickstart.html](site-gumshoe/quickstart.html) ·
**приключение:** [site-gumshoe/adventure.html](site-gumshoe/adventure.html)

GUMSHOE устроен наоборот по отношению к обычным играм: **расследование не бросают кубик**.
Есть способность и подходящая сцена — есть улика, без броска. Забуксовать из-за неудачного
кубика невозможно.

Ключевое совпадение с сериалом — **правило твари**: пока слабость существа не установлена,
любая атака наносит ровно 1 урона. Братья Винчестеры почти никогда не «просто проваливают»
проверку: они теряют ночь, шумят, злят шерифа и всё равно находят зацепку.

### Карточки GUMSHOE

У каждой из 354 записей: **Пул** (запас очков), **Порог попадания**, **урон**,
**потеря Стабильности** (провал / успех), **правило твари** — что именно её убивает,
и **улики** — 2–3 способности, которыми это правило узнаётся, с указанием Сл.

### Что отличает эту версию от базового GUMSHOE

**Два счётчика вместо одного.** `Стабильность` — краткосрочные нервы, восстанавливаются
через Источники стабильности, то есть через живых людей. Не сном и не бутылкой.
`Убеждённость` — вера в то, что мир познаваем и стоит того; **не восстанавливается
обычными способами и не растёт никогда**. На нуле охотник уходит из дела — и становится
кем-то другим (таблица на 1d6).

**Правило твари.** Тварь нельзя убить не потому, что мастер запрещает, а потому что мир
так устроен. Правило устанавливается расследовательскими способностями, и установить
его — событие серии, а не рядовой бросок.

**Обряды как работа, а не как заклинания.** Экзорцизм, ловушка дьявола, соляной круг,
освящение, сигил изгнания ангелов — у каждого пять параметров: способность, время, Сл,
компоненты, цена. Провал обряда страшнее, чем его отсутствие.

**Шесть архетипов с готовыми цифрами** плюс 18 узлов архетипа — постоянных бонусов,
привязанных к тому, как охотник работает.

# Третья редакция: «The Edge!»

**Сайт:** [site-edge/index.html](site-edge/index.html) ·
**правила:** [site-edge/rules.html](site-edge/rules.html) ·
**приключение:** [site-edge/adventure.html](site-edge/adventure.html)

Тот же бестиарий под авторскую модульную систему: **только d6**, пара кубиков — светлый
и тёмный, четыре атрибута Тело, Ловкость, Разум, Воля, раны и стресс.

Ключевое совпадение с сериалом: **в «The Edge!» провал без шага вперёд запрещён
правилами**. Светлый кубик показывает, насколько хорошо получилось; тёмный — цену.

У каждой карточки: **ЧЦ защиты** = 8 + Ловкость + доспех, **раны**, **стресс**,
**оружие** с бонусом и дистанцией, **не больше двух** особых способностей — это правило
самой системы, а не экономия места — и **проверки узнавания** слабости с ЧЦ.

### Откуда числа

Формулы выведены из статблоков D&D 5e и полностью приведены на странице правил:

| Показатель | Формула |
|---|---|
| Атрибут | round(модификатор D&D / 1,5) + 2, от 0 до 8 |
| Раны | 6 + Тело + round(CR / 2), от 3 до 40 |
| Стресс | 6 + Воля |
| Доспех | round((КД − 12) / 2), от 0 до 5 |
| ЧЦ защиты | 8 + Ловкость + доспех |
| Бонус оружия | round(средний урон атаки / 7), от 0 до 5 |

# Фирменный стиль

Сайт оформлен в визуальном языке сериала. Все эмблемы — **оригинальная графика**,
нарисованная для проекта в SVG; логотип Warner Bros. не используется и не воспроизводится.

| Знак | Что это | Где |
|---|---|---|
| **Ловушка дьявола** | пентаграмма в двойном круге с насечками | знак в шапке всех страниц, водяной знак в карточке существа |
| **Пентаграмма** | знак в круге | эмблема редакции D&D 5e, фавикон |
| **Звезда Людей Письма** | гексаграмма в круге | эмблема редакции GUMSHOE |
| **Соляная линия** | рассыпанная соль | разделитель перед подвалом |
| **Энохианское письмо** | полоса знаков | подвал главной, разделы книги |
| **Ночное шоссе** | перспектива дороги | фон героя главной, обложка книги |

Плюс **заставка серии** — светящийся заголовок с медленной пульсацией, как в титрах.

```
assets/
  brand.css               фирменные стили
  brand/
    devils-trap.svg       ловушка дьявола
    sigil-star.svg        пентаграмма
    men-of-letters.svg    звезда Людей Письма
    salt-line.svg         соляная линия
    enochian-band.svg     энохианское письмо
    road.svg              ночное шоссе
    impala.svg            чёрная машина
    favicon.svg           иконка сайта
```

**Как это сделано.** Знаки подключены **CSS-масками**, а не картинками: цвет берётся
из `currentColor`. Поэтому одна и та же эмблема работает и красной в шапке, и золотой
в разделителе, и чёрной на печати.

```css
.sig { background-color: currentColor; mask: var(--sig) center/contain no-repeat; }
.sig-trap { --sig: url("brand/devils-trap.svg"); }
```

> **Почему не `<img src="…svg">`.** `currentColor` внутри внешнего SVG, подключённого
> через `<img>` или `background-image`, **не наследуется** от страницы — знак рисуется
> чёрным. Поэтому все эмблемы идут через маску.

# Вёрстка книги правил

PDF «Охотников» — не распечатка веб-страницы, а свёрстанная книга: обложка во всю
страницу, титул, оглавление с номерами страниц, разделы частей, открывалки глав
с крупной цифрой, две колонки, врезки, таблицы с тёмными шапками, колонтитул
с названием главы и номером страницы, закладки PDF.

```bash
bash scripts/serve.sh                  # в одном окне
python3 scripts/build_gumshoe_pdf.py   # в другом → rules-gumshoe.pdf
```

Шесть шагов пайплайна:

1. [scripts/make_gumshoe_book.py](scripts/make_gumshoe_book.py) верстает
   `site-gumshoe/book.html` (тело) и `book-front.html` (обложка, титул, оглавление)
2. Chrome печатает тело книги
3. `pypdf` читает готовый PDF и находит, на какой странице начинается каждая глава
4. по этому списку печатается слой колонтитулов — по странице на каждую страницу книги
5. колонтитулы накладываются, номера страниц подставляются в оглавление
6. обложка, титул и оглавление печатаются заново и склеиваются с телом; ставятся закладки

**Почему так, а не через колонтитулы Chrome.** Chrome умеет печатать свои колонтитулы,
но их вид не настроить, а обложке они не нужны. Поэтому колонтитулы — отдельный PDF-слой:
полный контроль над шрифтом, линией и номером, и обложка остаётся чистой.

Нужен `pypdf` — скрипт сам поставит его в `scripts/_vendor`, если не найдёт.

### Грабли вёрстки под печать

- **`currentColor` не работает во внешних SVG.** Ни в `<img>`, ни в `background-image`.
  Знак рисуется чёрным. Поэтому декоративные фигуры на обложке встроены в HTML,
  а фоном идёт SVG с прописанным цветом.
- **Большая тень текста печатается прямоугольником.** `text-shadow` с размытием 60pt
  Chrome растеризует, и границы растра видно. Свечение заголовка на обложке поэтому
  убрано — вместо него радиальные градиенты.
- **Обложка во всю страницу требует отдельной `@page`.** Внутри обычных полей содержимое
  обрезается: `@page cover { margin: 0 }` плюс `page: cover`.
- **`break-before` внутри многоколоночного потока не срабатывает.** Разделы частей
  вынесены в отдельные блоки `.flow`, по одному на часть: тогда разрыв страницы работает
  надёжно.

# Публикация на GitHub Pages

Сайт собирается и публикуется автоматически при пуше в `master`
(workflow [.github/workflows/pages.yml](.github/workflows/pages.yml)).

```
push в master  →  python3 scripts/build_pages.py  →  public/  →  GitHub Pages
```

Пайплайн: забирает репозиторий, ставит Python, **проверяет, что все карточки бестиария —
валидный JSON** (падает, если нет), собирает `public/`, загружает артефакт и публикует
через `actions/deploy-pages`.

Структура внутри `public/` повторяет корень репозитория, поэтому относительные ссылки
между редакциями (`../site/img/`, `../assets/`) работают без правок.

Локальная проверка того, что уедет на Pages:

```bash
python3 scripts/build_pages.py
python3 -m http.server 8080 --directory public
```

# Методика

1. По MediaWiki API собран список страниц существ (1463 страницы в 72 категориях).
2. Страницы разделены на «виды/типы» и «именных персонажей»; вручную отобран мастер-список
   значимых записей (виды, Альфы, архангелы, Принцы Ада, Рыцари Ада, Всадники, боги
   пантеонов, ключевые именные сущности).
3. Для каждой записи загружен викитекст, из него вырезаны инфобокс, описание, силы
   и способности, слабости, характеристики, история и появления — получилась компактная
   выжимка 1–5 КБ.
4. По выжимкам написаны русские карточки по единым схемам (`scripts/SCHEMA*.md`)
   с автоматической проверкой: обязательные поля, допустимые категории и типы,
   характеристики в диапазоне, согласованность параметров, объёмы разделов.
5. Все 354 записи прошли валидацию в каждой из трёх редакций; сайт собирается одной
   командой.

**Про изображения.** 269 записей имеют реальный кадр из сериала. Остальные используют
аккуратную заглушку — эмблему категории и название. Подсунуть фотографию актёра вместо
монстра хуже, чем честная заглушка.
